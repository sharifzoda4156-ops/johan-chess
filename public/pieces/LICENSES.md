# Chess piece artwork

The five independent artwork collections are embedded without altering their SVG content. Each source SVG and its Git blob hash are in the corresponding JS module in this directory. Source: https://github.com/lichess-org/lila/tree/master/public/piece ; per-set license: https://github.com/lichess-org/lila/blob/master/COPYING.md .
