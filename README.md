# Johan Chess v0.1
Бесплатный персональный анализатор завершённых шахматных партий. Русский интерфейс, мобильная вёрстка, Stockfish 18 Lite Single в Web Worker, chess.js 1.4.0 для легального разбора PGN.

## Запуск на ПК (Node.js 20+)
```sh
npm install
npm test
npm start
```
Открой http://localhost:4173. Для телефона в одной Wi-Fi сети: Linux/macOS `HOST=0.0.0.0 npm start`; PowerShell `$env:HOST="0.0.0.0"; npm start`. Затем открой на телефоне `http://IP_КОМПЬЮТЕРА:4173`. Разреши локальный порт в брандмауэре при необходимости. Не открывай порт всему интернету без HTTPS и ограничений запросов. Интернет нужен для установки и импорта партий. Движок анализирует локально в браузере; PGN вручную работает без внешнего API после установки.

## Что есть
- Импорт 30 последних стандартных партий из максимум трёх архивных месяцев Chess.com через серверный прокси официального PubAPI; ручной PGN, если API недоступен.
- Интерактивный просмотр ходов, переворот доски, график оценки, глубина 10/13/16, остановка анализа.
- Каждый ход: оценка лучшего и сыгранного варианта в одной позиции с одинаковой запрошенной глубиной; вариант лучшего хода. Это эвристика: глубина и результат поисков не гарантируют истинной оценки.
- Собственные категории и точность JC: логистическая модель шанса на победу от centipawn, потеря шанса, затем средняя точность полуходов; не официальные метрики Chess.com. Метка Brilliant намеренно отсутствует: нужен отдельный анализ жертвы и уникальности.
- Список до пяти наиболее существенных ошибок пользователя и переход к позиции до ошибки, экспорт отчёта JSON. Пока это упражнения на самостоятельный поиск; генератора проверяемых решений, долгосрочного профиля, автоматических объяснений причин ошибки и APK пока нет.

## Проверка и ограничения
Тесты метрик не требуют установки зависимостей. Полная установка, запуск движка, реальный импорт и проверка на Android требуют доступа к npm/Chess.com и браузера. В среде создания этот доступ недоступен; проверка интеграции обязательна. Движок загружается при запуске анализа. Не используй приложение для помощи в текущей партии.
