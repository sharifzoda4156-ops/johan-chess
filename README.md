# Johan Chess v0.1
Бесплатный персональный анализатор завершённых шахматных партий. Русский интерфейс, мобильная вёрстка, Stockfish 18 Lite Single в Web Worker, chess.js 1.4.0 для легального разбора PGN.

## Запуск на ПК (Node.js 20+)
```sh
npm install
npm test
npm start
```
Открой http://localhost:4173. Для телефона в одной Wi-Fi сети: Linux/macOS `HOST=0.0.0.0 npm start`; PowerShell `$env:HOST="0.0.0.0"; npm start`. Затем открой на телефоне `http://IP_КОМПЬЮТЕРА:4173`. Разреши локальный порт в брандмауэре при необходимости. Не открывай порт всему интернету без HTTPS и ограничений запросов. Интернет нужен для установки и импорта партий. Движок анализирует локально в браузере; PGN вручную работает без внешнего API после установки.

## Что есть
- Импорт 30 последних стандартных партий из максимум трёх архивных месяцев Chess.com через серверный прокси официального PubAPI; ручной PGN, если API недоступен.
- Интерактивный просмотр ходов, переворот доски, график оценки, глубина 10/13/16, остановка анализа.
- Каждый ход: оценка лучшего и сыгранного варианта в одной позиции с одинаковой запрошенной глубиной; вариант лучшего хода. Это эвристика: глубина и результат поисков не гарантируют истинной оценки.
- Собственные категории и точность JC: логистическая модель шанса на победу от centipawn, потеря шанса, затем средняя точность полуходов; не официальные метрики Chess.com. Метка Brilliant намеренно отсутствует: нужен отдельный анализ жертвы и уникальности.
- Список до пяти наиболее существенных ошибок пользователя и переход к позиции до ошибки, экспорт отчёта JSON. Пока это упражнения на самостоятельный поиск; генератора проверяемых решений, долгосрочного профиля, автоматических объяснений причин ошибки и APK пока нет.

## Проверка и ограничения
Тесты метрик не требуют установки зависимостей. Полная установка, запуск движка, реальный импорт и проверка на Android требуют доступа к npm/Chess.com и браузера. В среде создания этот доступ недоступен; проверка интеграции обязательна. Движок загружается при запуске анализа. Не используй приложение для помощи в текущей партии.

## Зависимости и лицензии
Stockfish.js (GPL-3.0): https://github.com/nmrugg/stockfish.js — исходники и инструкции сборки. chess.js (BSD-2-Clause): https://github.com/jhlywa/chess.js. При распространении сборки соблюдай лицензии зависимостей, включая предоставление соответствующего исходного кода Stockfish. Архив проекта не содержит сторонних бинарников.

## Android (alpha)
Устанавливаемое Android-приложение (APK), не требуется ПК или VPS при использовании. Нативная оболочка WebView загружает только локальные assets; Chess.com PubAPI запрашивается через Android HTTPS. Существующий Stockfish работает в Web Worker на телефоне. Android 8+ и актуальный Android System WebView. Сборка: Node.js 22, JDK 17, Android SDK 35, Gradle 8.9. В корне `npm install`, затем `gradle -p android :app:assembleDebug`. APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Workflow Android APK собирает debug APK как artifact на PR. Это alpha; проверка реальной сборки, Android WebView/Stockfish, входа и инференса обязательна перед релизом.

ИИ: официальный [Sign in with ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source), browser OAuth с PKCE/state/nonce и loopback; токены шифруются Android Keystore, не передаются JavaScript. Модели берутся из каталога текущего аккаунта. Responses API с store=false и stream=true, без запасного платного API. Только доступные аккаунту модели и лимиты; наличие Plus не гарантирует доступ. Один локальный профиль; выход сохраняет регистрацию для повторного входа, удаление регистрации позволяет зарегистрировать другой аккаунт. История диалога пока сессионная. Локально хранится до 30 завершённых анализов по нику и заметки; передача контекста только по кнопке «Спросить тренера». Память ChatGPT не импортируется. Функция экспорта JSON в Android пока не подключена к системному диалогу сохранения. Не использовать для текущих партий.

## Игровой режим
Тренировка против локального Stockfish: цвета белые/чёрные/случайный, Skill Level 0/3/6/10/15/20, 10+0 / 15+10 / 30+0 / без часов, FEN или начальная позиция. Адаптивный уровень хранится по нику и меняется на один шаг после выигранной/проигранной стандартной партии; ничья не меняет уровень. Это внутренняя шкала, не калиброванный Elo. Игра поддерживает легальные ходы chess.js, все превращения, мат, пат и автоматические ничьи по троекратному повторению/50 ходам (учебное упрощение FIDE). При флаге и голом короле соперника — ничья; прочие редкие случаи невозможности мата при флаге не реализованы. Часы работают по performance.now(); поведение при глубоком сне устройства нужно проверить на Android. Никакой оценки/ИИ в ходе тренировки. При окончании сохраняется PGN локально (до 30 партий); автоматически открывается отчёт и запускается анализ; кнопка «Разобрать партию» возвращает к отчёту или запускает недостающий анализ; «Разобрать с ИИ» заполняет запрос, но отправка только после нажатия «Спросить тренера». Можно переиграть позицию своей ошибки. При отмене или сбое движка партия не записывается как поражение. Автоматическая проверка ядра включена в npm test. Android WebView и реальное взаимодействие с Stockfish проверяются отдельно.

## Интерфейс
Android-first тёмная тема, зелёно-кремовая доска, оригинальные SVG-фигуры, нижняя навигация Играть / Анализ / Тренер. При активной тренировке другие разделы заблокированы, после завершения открывается анализ. Без заимствования логотипа, картинок или исходного кода Chess.com. Задачи и пазлы оставлены на следующий этап.

## Каркас академии
Главная, Задачи (пока заглушка), Учёба (чат с ИИ), Профиль (имя из проверенного ID token ChatGPT, при отсутствии — ник Chess.com; локальные показатели последних сохранённых тренировок и анализов). Игра и отчёт доступны из Главной. В ответах тренера `[[board:N]]` отображает мини-доску из фактической позиции перед полуходом с индексом N в переданном анализе; можно переключать сыгранный и лучший ход. Позиции фиксируются в момент запроса, неверные ссылки не рисуются. APK собирается только вручную: Actions → Android APK → Run workflow (main). Автоматические сборки временно отключены; локальные npm test доступны. Реальный Android и вход в ChatGPT требуют ручного теста.

Имя берётся только из подписанного ID token при входе; для уже авторизованного аккаунта без имени может понадобиться повторный вход. Статистика пока ограничена локальной историей (до 30 записей каждого типа); не является статистикой всего аккаунта Chess.com.

## Задачи — только открытая база Lichess
Источник: https://database.lichess.org/#puzzles, CC0. В main хранится 1000 исходных записей, перенесённых без изменений из опубликованного starter.json ветки puzzle-catalog. APK включает этот набор без сетевой зависимости от публикации каталога. Все ходы проверяются chess.js; первый ход в CSV применяется за соперника, затем пользователь решает опубликованную комбинацию, ответ соперника выполняется автоматически. Для мата в один разрешены другие матующие ходы. Выбор темы и рейтинга; подсказка, решение и статистика. Самодельные и персонально сгенерированные пазлы удалены. Разбор собственных партий остаётся в Анализе/Учёбе. Старый прогресс синтетических задач не переносится. APK workflow только ручной.

## Адаптивная тактика
По умолчанию задачи подбираются близко к локальной цели 1100 по опубликованному рейтингу Lichess. После первой чистой попытки цель растёт, после ошибки/подсказки/показа решения падает; пропуск не меняет цель. Повторные решения и ранее решённые задачи не влияют на оценку. Ручной выбор диапазона остаётся доступным. Профиль показывает статистику первых попыток после этого обновления, включая результаты по официальным тегам (одна задача может относиться к нескольким темам). Сложность не является рейтингом игрока Lichess/Chess.com. По разрешению на отправку учебного контекста тренер получает агрегированные показатели тактики, без исходных задач и решений. Данные локальны, APK собирается вручную.

## Полная база без увеличения APK
Отдельный workflow **Publish Lichess puzzle data** (теперь только ручной запуск, первоначальная публикация уже выполнена) скачивает официальный CSV.zst, сохраняет все записи с валидным форматом (отклонённые строки считает), разбивает по рейтингу на блоки до 1000 задач. Блоки — диапазоны байтов внутри файлов до 128 МиБ в версионированном GitHub Release. Каталог и 1000 проверенных стартовых задач размещаются в отдельной ветке `puzzle-catalog` только после загрузки и проверки HTTP 206 + SHA-256 на каждом файле. Первая сборка APK больше не зависит от успешной публикации: стартовый набор уже находится в main. Последующие обновления каталога не требуют пересборки APK. Приложение запрашивает только подходящий блок, проверяет размер и SHA-256, хранит загруженные блоки и каталог в IndexedDB с LRU-лимитом 50 МиБ полезной нагрузки (служебные накладные расходы браузера отдельно). В памяти до четырёх загруженных блоков плюс стартовый набор. При недоступности GitHub используются локальные задачи. Для полной базы проверка легальности производится при выборе задачи; все 1000 стартовых задач проверяются до публикации. Прогресс хранится отдельно от кэша. Публичный репозиторий обязателен. Сборка APK остаётся только ручной. Ветка puzzle-catalog и стартовый набор подтверждены. Полный каталог, загрузку на Android и размер APK требуется проверять отдельно.

## Постоянная память тренера
Учёба хранит локально до 50 полных пар сообщений (до 750000 байт в оценке UTF-16), мини-доски с проверкой сохранённых ходов, цели, ежедневное время, редактируемый план и заметки. Ключ памяти — SHA-256 от issuer и подписанного subject OpenAI плюс нормализованный ник игрока; имена и email не используются как ключ. Выход скрывает память, повторный вход в тот же аккаунт и ник восстанавливает её. Удаление диалога и удаление всей памяти учёбы — отдельные действия; историю партий можно удалить отдельно. В интерфейсе сначала видны последние 20 сообщений, более старые можно раскрыть. Опция передачи диалога сохраняется для аккаунта и ника. В новом запросе передаются только последние до 12 сообщений и до 48000 символов при включённой опции, а план и заметки — всегда; опция отправки партии/статистики независима. Синхронизации с историей ChatGPT или между устройствами нет. План предлагается в чате и сохраняется пользователем в редактируемое поле. Генерация новых шахматных задач запрещена инструкцией тренера; задачи остаются из Lichess. Данные учебной памяти находятся в локальном WebView storage, не в Android Keystore; токены по-прежнему в защищённом хранилище. APK workflow ручной.

## Библиотека шахмат
В «Учёбе» доступна отдельная библиотека без пятой вкладки. Дебюты: оригинальные TSV A–E из https://github.com/lichess-org/chess-openings (CC0), 3865 строк, поиск по ECO/английскому названию/ходам, просмотр линии, игра из позиции и обсуждение с тренером. Эндшпиль: переход к существующим задачам Lichess по официальным тегам (https://lichess.org/training/themes), не полный теоретический курс. Исторические партии: семь подлинных записей ходов из https://theoreticalnovelty.com/ (public domain game scores; ссылки у каждой партии), без копирования авторских комментариев. Просмотр и анализ обеих сторон локальным Stockfish, затем обсуждение с ИИ; чужие партии не сохраняются в личную статистику. Дебютные материалы и исторические PGN доступны офлайн; загрузка задач использует отдельный механизм базы. Автоматическая сборка APK остаётся выключенной.

## Проверки без сборки APK
Workflow `Quality checks` запускает Node-тесты и проверку синтаксиса модулей, без Android SDK, Gradle и сборки APK. Для публикации базы проверяются тесты загрузчика и стартового набора независимо от остальных модулей. APK по-прежнему собирается только вручную.

## Оформление
Пять локальных тем с оригинальными SVG из Lichess: Classic (chessnut), Tournament (cburnett), Spatial, Celtic, Rhos (rhosgfx). Независимые цветовые палитры. Выбор в профиле с предпросмотром, сохранением на устройстве и применением ко всем доскам, включая карточки ИИ. Без загрузок из сети и копирования фирменной графики Chess.com. Исходные SVG, Git blob-хеши, авторство и лицензии в `public/pieces/`. GPL применяется к artwork CBurnett, исходники включены. Автоматическая сборка APK выключена.
