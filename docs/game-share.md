# Game sharing (Android)
Android Sharesheet receives text PGN, public Lichess or Chess.com game links, and PGN content URIs. MainActivity handles both cold start and onNewIntent. Received items wait in a bounded in-memory inbox (three items, 1 MiB each); do not interrupt a live game, analysis or coach request. Validate legal, finished standard PGNs before opening review; up to 100 games. No automatic Stockfish analysis. For Chess.com links use the configured participant nickname and search the last three public monthly archives for exact game URL; older or unavailable games require PGN. Lichess uses official public game export with fixed host, discards private player tokens. No arbitrary HTTP URLs or cookies. Outbound Sharesheet supports text and a temporary PGN file via narrowly scoped FileProvider with read grant. No broad storage permission. Fair-play gate on native and UI paths. The inbox is not durable if Android kills the process. Real-device share target, URI permission, cold/warm launch and chooser compatibility require testing.
