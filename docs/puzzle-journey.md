# Johan Chess tactics modes
Inspired by [Chess.com Puzzle points](https://support.chess.com/en/articles/9681952-what-are-puzzle-points-on-chess-com) and [Daily Puzzle](https://support.chess.com/en/articles/8708990-how-does-the-daily-puzzle-work), with independent UI, data and scoring.
- Journey: 8 ranks, 20 levels each; 80 XP initially, costs rise gradually. Base XP 15/22/30 according to published puzzle difficulty relative to local target. Speed +5 or +10 (soft target, no timeout), streak up to +10, third clean puzzle of local day +20, personal hardest +10, every 50 unique solves +25. Wrong moves, hints, reveal or skip break streak; only clean unique IDs earn XP. XP is not a rating. Timer uses monotonic active time and pauses when app, screen or ladder is hidden. Local per-nickname persistence.
- Daily: deterministic rotation of the bundled Lichess pack, using local calendar day. Same pack version gives same daily position across users, no network required. Last seven days available, 5 hearts, unlimited retries; a revealed answer does not count. Streak independent of journey and classic. Pack updates can change the rotation; a previously completed date remembers its ID. No copied Chess.com daily content.
- Classic: existing unlimited adaptive/topic practice and GitHub pack fetching remain.
- All positions and solutions from CC0 Lichess. No new subscription or remote service. Existing adaptive estimate remains separate from XP.
- Device verification: exercise mode switching, returning to ladder mid-attempt, background timer, offline daily, date change, wrong move/hint/reveal, local progress reload, remote loading, promotion and endgame link from library. No measured device performance claim.
