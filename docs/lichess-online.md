# Online Lichess alpha
Official API and fair play: https://lichess.org/api ; https://lichess.org/page/fair-play ; https://lichess.org/page/api-tips .
Android OAuth PKCE S256 and encrypted token, no VPS. Browser loopback callback checks state. Native bridge uses fixed Lichess endpoints and separates ordinary serial requests from event/game/seek streams. 429 waits one minute.
Standard real-time chess only; automatic seek 10+0, 15+10, 30+20; direct 3+2 and 5+0 challenges also allowed. Server decides pairing, moves, clocks, outcomes and ratings. UI clocks are projections. Matchmaking and live game lock training navigation, cancel local engine work, and reject coach inference. Completed PGN can be opened in Stockfish.
Social: Lichess follow/unfollow, account ratings, profile URL via Android share, incoming challenge refresh, completed standard-game history. No mutual-friend system, private messages or notifications when app is closed. Lichess and Chess.com identities remain separate.
Device verification required: OAuth loopback; seek cancellation and game-start race; live stream reconnect, background/resume, promotion, draw/resign/abort, end status, unsupported variants, 429, history and share. No Android build or live two-account test performed here.

The online lock is persisted across process restarts for unresolved matches. Final server status is followed by a fresh ongoing-game check before releasing the lock; a revision guard rejects stale reconciliation. An official browser link is provided if a game cannot be rendered in the alpha. Play on other devices while offline is not detectable; fair play remains the user's responsibility. The friends view loads up to 200 followed players and game history up to 20 recent records.

Fair-play hardening: native FLAG_SECURE for locked matchmaking/live games, no screenshot/recording/task preview on supported Android; block external profile/game launch and Android Back while locked. App engine registry terminates all workers and disallows new ones; coaching is gated on both sides. Online board has no legal-target dots or engine hints. A persisted per-game 60-second absence deadline uses a monotonic epoch clock while running; foreground focus plus connected game stream clears it only before expiry. At expiry, moves remain disabled and a server resignation is attempted via serialized recovery; no local loss is fabricated. A disconnected or killed process cannot guarantee resignation at exactly 60 seconds; stored deadline resumes on restart. Lichess may end/abort the game under its own rules first. Other devices, rooted phones, cameras and OS restrictions are outside this protection. Native device and network tests still required.

On abrupt process death, a five-second foreground heartbeat provides a conservative restart deadline (last healthy time + 65 seconds) if no ordinary absence deadline was saved. Native Android compilation is added to PR checks; this does not replace live two-account/device testing.
