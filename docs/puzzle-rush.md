# Speed tactics
Reference: https://support.chess.com/en/articles/8608686-how-do-puzzles-work-on-chess-com — 3/5 minute rounds and survival, ending after three failed puzzles, independent of rated puzzles. Johan Chess uses a separate offline Lichess pool, progressive difficulty target (600 + 65 per correct answer, capped at 2800), no duplicate IDs in one round, one point per correct puzzle, manual Next after a failed or completed line, with unlimited rest between puzzles. The timer starts when the first board is ready, freezes after each completed or failed puzzle, and resumes only after Next has prepared the next board. During a live puzzle background time counts; a rest never reveals the next position. Both countdown and Survival elapsed time exclude rest. This is an intentional custom rule, not a continuous Chess.com rush. A stopped round is stored but cannot set a record. The history retains 90 recent runs, separate bests per mode, per local nickname. Solution review uses the published line, not engine evaluation. No server ranking, multiplayer or subscription. The bundled pool is finite; remote packs are not fetched during a timed run. Device checks: deadline during promotion, third mistake, background and return, navigation exit, offline load, record and history reload, result replay, screen sizes.
